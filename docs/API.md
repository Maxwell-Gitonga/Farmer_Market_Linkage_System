# REST API reference

Base URL `http://localhost:8080/api`. JSON in/out. Every call except those marked *public* needs
`Authorization: Bearer <token>` (returned by login/register). Errors: `{ "status": 400, "message": "…" }`.

## Auth (User Management Module)
| Method | Path | Role | Description |
|---|---|---|---|
| POST | `/auth/register` | public | `{role: FARMER\|BUYER, name, phone, password, location, email?, preferences?}` → `{token, user}` |
| POST | `/auth/login` | public | `{phone (or admin email), password, role?}` → `{token, user}` |
| GET / PUT | `/auth/me` | any | Profile / update name, email, location, preferences |

## Market insights
| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/market/meta` | public | Crops (emoji, shelf life) and county markets |
| GET | `/market/prices/latest?crop=` | any | Latest price per crop/county with 7-day change |
| GET | `/market/prices/history?crop&county&days` | any | Price history (county or national average) |
| GET | `/market/forecast?crop&county&weeks` | any | Last 60 days + weekly price forecasts with ranges |
| GET | `/market/demand?crop` | any | Weekly demand history + 4-week forecast and trend |
| GET | `/market/best-markets?crop&county&quantity&date` | any | County markets ranked by net price after transport |
| POST | `/market/quick-estimate` | any | Listing-form preview `{cropType, location, harvestDate, quantity}` |

## Products
| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/products?crop&county&maxPrice&sort` | any | Available listings (`sort`: newest, price_asc, price_desc, quantity, harvest) |
| GET | `/products/{id}` | any | Listing detail + 30-day price trend |
| GET | `/products/mine` | FARMER | Own drafts, live and recently sold listings |
| POST | `/products` | FARMER | addListing → `{product (DRAFT), recommendation}` |
| GET | `/products/{id}/recommendation?refresh` | FARMER | Stored (or refreshed) price recommendation |
| POST | `/products/{id}/publish` | FARMER | `{price, acceptedRecommendation}` → AVAILABLE + matched buyers |
| GET | `/products/{id}/matches` | FARMER | Matched buyers |
| PUT / DELETE | `/products/{id}` | FARMER | Modify / delete (REMOVED) |

## Farmer / Buyer
| GET | `/farmer/dashboard` | FARMER | Dashboard cards, listings, matched buyers, recent sales |
|---|---|---|---|
| GET | `/buyer/recommendations?limit` | BUYER | Listings ranked for the buyer |

## Transactions
| Method | Path | Role | Description |
|---|---|---|---|
| POST | `/transactions` | BUYER | purchaseProduct `{productId, quantity}` → `{transactionId, message: "Purchase confirmed"}` |
| GET | `/transactions/mine` | any | Farmer sales / buyer purchases / admin last 30 days |
| PATCH | `/transactions/{id}/status` | FARMER/BUYER/ADMIN | `{status: COMPLETED\|CANCELLED}` |

## Messages
| GET | `/messages/threads` | FARMER/BUYER | Conversations |
|---|---|---|---|
| GET | `/messages/thread/{counterpartId}` | FARMER/BUYER | Messages with one person (marks them read) |
| POST | `/messages` | FARMER/BUYER | `{counterpartId, content, productId?}` |

## Admin
| Method | Path | Description |
|---|---|---|
| GET | `/admin/overview` | Counters + ML status |
| GET | `/admin/users?role&status` | All users |
| PATCH | `/admin/users/{role}/{id}/status` | `{status: ACTIVE\|SUSPENDED\|BANNED, reason?}` (ACTIVE on a pending farmer = approve) |
| POST | `/admin/farmers/{id}/approve` | Approve a farmer |
| GET | `/admin/listings?status` | Listings |
| POST | `/admin/listings/{id}/remove` | `{reason}` |
| GET | `/admin/logs?action` | System activity |
| GET | `/admin/reports?days` / `/admin/reports/export?type=transactions\|listings\|users&days` | Reports / CSV |
| POST | `/admin/market-prices` / `/admin/market-prices/import` (multipart `file`) | Add / import market prices |
| GET | `/admin/ml/status` · POST `/admin/ml/retrain` | Model status & metrics · retrain on database data |
| GET | `/health` (public) | Backend, database and ML module status |

## Python ML module (`http://localhost:8000`, called by the backend)
`GET /health`, `GET /meta`, `GET /metrics`, `POST /train`, `POST /predict/price`, `POST /forecast/demand`,
`POST /recommend/price`, `POST /recommend/markets`, `POST /recommend/matches`.
Interactive documentation: **http://localhost:8000/docs** (Swagger UI generated by FastAPI).
